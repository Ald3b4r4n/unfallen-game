# Save/Load

## Contexto
Tipo de jogo: pixel-art
Engine: phaser
Target: web

## Objetivo
Descrever decisões, restrições e critérios para este eixo do preset game.

## Critérios mínimos
- Manter rastreabilidade com o GDD.
- Validar impacto em UI/HUD, controles, acessibilidade e performance.
- Registrar riscos técnicos e decisões pendentes antes da implementação.

## Exemplo opcional
Uma stack web pode combinar Phaser.js para gameplay, Next.js para shell web, MongoDB ou Firebase para dados, e Vercel para hospedagem. Esta é apenas uma referência, não uma obrigação do preset.
