## Observações de Licenciamento e Criação de Artes

Na fase de criação de artes do Unfallen, lembrar que o projeto poderá usar:
* criação de artes originais via Nano Banana no Antigravity;
* avaliação/importação de skills de arte a partir de `https://github.com/sickn33/antigravity-awesome-skills`;
* assets gratuitos, CC0 ou licenciados corretamente;
* placeholders temporários durante MVP.

### Regras Obrigatórias:
1. **Não copiar** assets pagos por print, recorte, reconstrução ou IA.
2. **Não usar** assets pagos sem a devida compra/licença comercial explícita.
3. Todo asset utilizado deve ter sua **origem, licença e uso permitido registrados** formalmente neste documento.
4. **IA pode ser usada** unicamente para criar arte original baseada em descrições próprias do Unfallen, sem replicar sprites, tiles, silhuetas, animações ou composições protegidas de terceiros.
5. **Skills externas** devem ser avaliadas tecnicamente antes de seu uso, instaladas apenas se compatíveis com o projeto e devidamente registradas no histórico de governança.
