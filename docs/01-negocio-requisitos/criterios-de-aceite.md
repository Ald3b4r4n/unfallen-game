# Critérios de Aceite

Esta tabela lista os critérios de aceite principais para cada Requisito Funcional (RF) estabelecido para o MVP de **Unfallen**.

| Código | Requisito | Critério de Aceite Principal |
|---|---|---|
| **[RF-001](file:///d:/Projetos/Unfallen/.sdd-master/requirements/rf/RF-001.md)** | Menu e Login | Login via Firebase Authentication libera botões de jogo e carrega o save correto. |
| **[RF-002](file:///d:/Projetos/Unfallen/.sdd-master/requirements/rf/RF-002.md)** | Movimentação Isométrica | Protagonista se move na diagonal com WASD sem tremer câmera nem atravessar paredes físicas. |
| **[RF-003](file:///d:/Projetos/Unfallen/.sdd-master/requirements/rf/RF-003.md)** | Combate e Estamina | Ataques (corpo a corpo e pistola) atingem inimigos com base na mira do mouse; esquiva consome estamina. |
| **[RF-004](file:///d:/Projetos/Unfallen/.sdd-master/requirements/rf/RF-004.md)** | Gerenciamento de Inventário | Abertura do inventário (`I`) pausa o jogo; itens (curativo/pilha) curam vida ou lanterna ao clique. |
| **[RF-005](file:///d:/Projetos/Unfallen/.sdd-master/requirements/rf/RF-005.md)** | Exploração e Coleta | Dica visual de "Pressione E" surge perto de gavetas/viaturas; itens coletados sobem para o inventário. |
| **[RF-006](file:///d:/Projetos/Unfallen/.sdd-master/requirements/rf/RF-006.md)** | Investigação Narrativa | Interação (`E`) com pistas abre janela de leitura textual; rádio de evacuação emite chiado. |
| **[RF-007](file:///d:/Projetos/Unfallen/.sdd-master/requirements/rf/RF-007.md)** | Obstáculos e Puzzles | Mensagem na tela avisa tranca; chave certa no inventário ou acionar gerador libera a passagem. |
| **[RF-008](file:///d:/Projetos/Unfallen/.sdd-master/requirements/rf/RF-008.md)** | Save em Nuvem | Checkpoints salvam progresso na nuvem de forma assíncrona; se offline, salvam em LocalStorage. |
| **[RF-009](file:///d:/Projetos/Unfallen/.sdd-master/requirements/rf/RF-009.md)** | Interface - HUD | HUD exibe dinamicamente saúde, estamina, bateria da lanterna, contagem de balas e objetivo ativo. |
| **[RF-010](file:///d:/Projetos/Unfallen/.sdd-master/requirements/rf/RF-010.md)** | Painel de Cheats | Atalho especial abre painel de depuração em ambiente de testes; desativado em produção. |
